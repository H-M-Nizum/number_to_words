# Amount in Words for Odoo 19

Odoo app **number_to_words**: writes numbers and amounts in words, on any model and any integer, float or monetary
field, on forms and on PDF reports. You choose the model, the field and the position yourself (no code).

* **Built in:** English, Bangla (বাংলা), Hindi (हिन्दी), Urdu (اردو)
* **Automatic:** Spanish, Arabic, French, German, Portuguese, Russian, Italian, Turkish, Indonesian, Japanese,
  Korean, Vietnamese, Persian and about 30 more, in the language of each user (Odoo's own `num2words` engine)
* One module for every Odoo app, no external dependency, free.

The module is in the folder [`number_to_words`](number_to_words). Its user manual is in
[`number_to_words/doc/USER_MANUAL.md`](number_to_words/doc/USER_MANUAL.md).

## Install
1. Copy the folder `number_to_words` into an addons path of your Odoo 19 server.
2. Restart Odoo, enable developer mode, *Apps → Update Apps List*, install **Amount in Words**.
